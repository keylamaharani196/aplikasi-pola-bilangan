# Roadmap Pengembangan

## Tahap 1 — Analisis kebutuhan
- [x] Membaca dokumen hasil wawancara yang tersedia.
- [x] Mengidentifikasi temuan IL, EL, GL, dan konteks.
- [x] Menurunkan temuan menjadi kebutuhan awal.
- [ ] Memastikan batas materi dengan dosen/guru.
- [ ] Jika memungkinkan, menggali kebutuhan dari informan tambahan.

**Output:** `analisis-wawancara.md` dan `prd.md`.

## Tahap 2 — Desain
- [x] Menyusun struktur halaman.
- [x] Menyusun alur pengguna.
- [x] Menentukan prinsip mobile-first.
- [ ] Membuat mockup visual final.
- [ ] Meminta masukan guru/dosen atau calon pengguna.

**Output:** `desain.md`.

## Tahap 3 — Persiapan konten
- [x] Menentukan urutan materi awal.
- [x] Menyusun contoh dasar.
- [ ] Memeriksa seluruh materi dan soal.
- [ ] Menyusun variasi latihan bertingkat.
- [ ] Memeriksa kunci jawaban dan pembahasan.

**Output:** `konten-pembelajaran.md`.

## Tahap 4 — Implementasi MVP
- [ ] Membuat struktur proyek.
- [ ] Membuat beranda dan navigasi.
- [ ] Membuat halaman materi.
- [ ] Membuat visualisasi pola.
- [ ] Membuat contoh dan pembahasan.
- [ ] Membuat latihan dan umpan balik.
- [ ] Menyesuaikan tampilan smartphone.

**Output:** aplikasi web versi awal.

## Tahap 5 — Pengujian dan revisi
- [ ] Menjalankan tes fungsional.
- [ ] Menguji pada browser Android.
- [ ] Menguji ketepatan konten matematika.
- [ ] Melakukan uji coba pengguna dengan persetujuan.
- [ ] Memperbaiki temuan pengujian.

**Output:** catatan pengujian dan versi revisi.

## Tahap 6 — Deployment
- [ ] Memilih layanan static hosting.
- [ ] Menghubungkan repository.
- [ ] Mempublikasikan aplikasi melalui HTTPS.
- [ ] Membuka URL di smartphone Android.
- [ ] Memeriksa ulang seluruh fitur setelah deployment.

**Output:** URL aplikasi yang dapat diakses.

## Prioritas pengerjaan

Kerjakan berurutan: konten dan ketepatan matematika → fungsi inti → tampilan smartphone → pengujian → publikasi. Fitur tambahan seperti akun, database, leaderboard, atau AI tidak perlu dibuat sebelum kebutuhan MVP terbukti.
