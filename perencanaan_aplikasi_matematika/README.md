# Dokumen Perencanaan Aplikasi Pembelajaran Pola Bilangan

Kumpulan dokumen ini menjadi landasan sebelum pengembangan aplikasi web pembelajaran **Pola Bilangan Ganjil dan Genap** yang dirancang agar nyaman digunakan melalui smartphone, khususnya Android.

## Isi folder

| File | Kegunaan |
|---|---|
| `prd.md` | Product Requirements Document: tujuan, pengguna, masalah, kebutuhan, fitur, dan kriteria keberhasilan |
| `analisis-wawancara.md` | Ringkasan temuan wawancara dan keterkaitannya dengan kebutuhan aplikasi |
| `desain.md` | Struktur halaman, alur pengguna, prinsip UI/UX, dan rancangan responsif |
| `arsitektur.md` | Gambaran teknis aplikasi dan alur kerja sistem |
| `cloud.md` | Rencana hosting, deployment, domain, HTTPS, dan pemeliharaan |
| `konten-pembelajaran.md` | Rancangan materi dan contoh pembelajaran |
| `pengujian.md` | Rencana pengujian fungsi, materi, dan tampilan smartphone |
| `roadmap.md` | Urutan pekerjaan dari persiapan sampai rilis |

## Status dokumen

Dokumen ini merupakan **rancangan awal tahap Analysis dan perencanaan**. Belum ada aplikasi yang dikoding atau dipublikasikan. Keputusan teknis dapat disesuaikan setelah kebutuhan tugas, kemampuan pengembang, dan uji coba dengan pengguna diperiksa.

## Prinsip penting

1. Utamakan keterbacaan pada layar smartphone.
2. Gunakan kalimat singkat dan instruksi yang jelas.
3. Tampilkan visual seperlunya, bukan dekorasi berlebihan.
4. Berikan contoh dan pembahasan secara bertahap.
5. Sediakan latihan dari tingkat mudah menuju lebih menantang.
6. Jangan menyimpan nama atau data pribadi siswa jika tidak benar-benar diperlukan.
