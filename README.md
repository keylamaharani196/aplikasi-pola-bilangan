# MathLearn – Media Pembelajaran Pola Bilangan

## 1. Deskripsi Proyek

MathLearn merupakan media pembelajaran matematika berbasis web yang dirancang untuk membantu siswa SMP memahami materi pola bilangan ganjil dan genap. Aplikasi ini dapat diakses melalui komputer maupun smartphone, khususnya perangkat Android.

Media pembelajaran ini menyajikan materi, rumus, contoh soal, serta latihan interaktif untuk membantu siswa memahami konsep pola bilangan secara bertahap.

## 2. Tujuan Pengembangan

1. Membantu siswa memahami pengertian pola bilangan ganjil dan genap.
2. Memudahkan siswa mengenali pola dan menentukan suku tertentu.
3. Menyediakan pembelajaran matematika yang interaktif.
4. Membantu siswa mengevaluasi pemahamannya melalui latihan soal.

## 3. Materi Pembelajaran

### A. Pola Bilangan Ganjil

Bilangan ganjil adalah bilangan bulat yang tidak habis dibagi 2.

Contoh: 1, 3, 5, 7, 9, 11, 13, dan seterusnya.

Rumus suku ke-n:

**Un = 2n - 1**

Contoh:
U10 = 2(10) - 1 = 19.

### B. Pola Bilangan Genap

Bilangan genap adalah bilangan bulat yang habis dibagi 2.

Contoh: 2, 4, 6, 8, 10, 12, 14, dan seterusnya.

Rumus suku ke-n:

**Un = 2n**

Contoh:
U12 = 2(12) = 24.

### C. Sifat Operasi Bilangan Ganjil dan Genap

- Ganjil + ganjil = genap.
- Genap + genap = genap.
- Ganjil + genap = ganjil.
- Ganjil × ganjil = ganjil.
- Genap × genap = genap.
- Ganjil × genap = genap.

## 7. Cara Menjalankan Aplikasi

1. Unduh atau clone repository.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan file `index.html` menggunakan ekstensi Live Server.
4. Aplikasi akan terbuka melalui browser.
5. Pengguna dapat mempelajari materi dan mengerjakan latihan soal.

## 8. Pengujian

Pengujian dilakukan untuk memastikan halaman, navigasi, materi, dan latihan interaktif dapat berjalan dengan baik.

Lima latihan yang disediakan meliputi:

3. Menentukan suku ke-15 bilangan ganjil.
4. Menentukan suku ke-20 bilangan genap.
